# fantasyRTwP

奇幻版「路線圖 roguelite ＋ 即時暫停（RTwP）小隊戰鬥」。

- 規格：[SPEC.md](SPEC.md)（戰鬥系統總規格）、[SPEC_SLICE2.md](SPEC_SLICE2.md)（切片 2：路線圖循環＋操作改版）、[SPEC_SLICE3.md](SPEC_SLICE3.md)（切片 3：職業變體＋戰術地形＋新敵人）
- 實作守則：[AGENTS.md](AGENTS.md)
- 引擎：Phaser 3 + TypeScript + Vite，測試用 Vitest

目前階段：切片 1、2 已完成；**切片 3 —— 職業變體（第一批 4 個）＋戰術地形＋新敵人** 已實作，等待試玩回饋。

## 指令

```bash
npm install
npm run dev                      # 開發伺服器（標題 → 組隊 → 路線圖 → 戰鬥／事件／休息 → 結算）
npm run build                    # 型別檢查＋打包到 dist/
npm test                         # 模擬層單元測試
npm run autobattle -- --runs 200 # 無畫面單場自動對戰，輸出勝率與平均傷害
npm run autorun -- --runs 100    # 無畫面整趟自動遠征（隨機組隊）：通關率、抵達層數、陣亡、金幣、戰鬥時間、全滅層數、各職業通關率
npm run autorun -- --runs 100 --fixed  # 同上，但隊伍固定為四個 Archetype（與切片 2 比較用）
npm run autorun -- --runs 20 --style deliberate  # 沉穩節奏的遠征（腳本很粗糙，只用來確認關卡打得完、不當機）
npm run perf                      # 怪群效能：80 名敵人時每節拍的 sim 耗時；hordePass 統計；深淵礦坑沿路點推進的統計
```

`autobattle` 其他參數：`--seed 1`（起始種子）、`--zoc pin|disengage|off`、`--noscript`（英雄只用閒置行為，模擬「亂按」）。
網址加上 `?seed=123` 可以指定戰鬥種子。

## 操作（行動版：沉穩節奏，目前的主要模式，SPEC_SLICE5）

遠征與快速戰鬥的小地圖遭遇預設都是**沉穩節奏**（整體變慢、每名英雄一招主動技能、所有攻擊都是攻擊移動）：

| 操作 | 效果 |
|---|---|
| 點英雄卡上半（名字） | 選取這名英雄；可以同時選多名；**再點一次取消**。雙擊：鏡頭移過去 |
| 點地圖上一點（或敵人） | 已選英雄**攻擊移動**過去，途中自動接戰（不能指定普攻目標）；下完指令**不會**取消選取（`GAME_CONFIG.deselectAfterOrder`） |
| 點英雄卡下半（技能鈕） | 發動那名英雄唯一的主動技能；需要目標時再點地圖：**打點擊位置最近的敵人（或友軍）**，不必精準點到單位；再點一次技能鈕取消 |
| 沙漏（卡片上方左側） | 暫停／繼續（空白鍵也可以）；暫停時沙漏停止並變成金色 |
| 拖曳地圖 | 移動鏡頭（遠近固定，不能縮放；旋鈕是 `src/config.ts` 的 `battleZoom`）；拖到卡片等面板上也會繼續拖，放開才結束 |
| 全選鈕（沙漏右邊） | 有英雄沒被選取時按下＝全選；已經全選時按下＝全部取消 |

畫面是**正角俯視**（地圖是正方格、保留俯角；角色仍用預渲染 sprite；地面、牆、門用程式畫），玩家往畫面上方推進；投影旋鈕在 `src/config.ts` 的 `ortho`（`pxPerM`、`squash`、`heightPxPerM`、`rotation`）。畫面外看得到的敵人會在畫面邊緣顯示紅色光暈，越強（最大生命越高）越大（`src/game/render/visual.ts` 的 `VISUAL.offscreen`）。
手機請**直拿**（四張卡片在下緣）；也可以「加入主畫面」全螢幕執行。路線圖上點節點一下看說明、再點一下前往。

卡片的**水位**就是行動條：準備動作時從下往上填滿，填滿時行動生效。地面上的細線是每個單位目前的攻擊目標（藍：英雄、紅：敵人）。
英雄帶**職業被動**（`src/sim/data/passives.ts`）：戰士橫掃＋嘲諷光環、狂戰士血怒、遊俠穿透箭、盜賊刺殺、法師震擊、咒術師咒彈、牧師聖鎚、煉金術士手榴彈；牧師的主動技能是治療藥瓶，煉金術士的火焰瓶會在地上留下燃燒區（持續效果的通用 helper：`src/sim/zones.ts`）。英雄卡右上角顯示身上的狀態圖示。
**敵人與關卡（S5-3）**：遠征每個戰鬥節點生成一張 48 × 48、有迷霧的關卡（`src/run/deliberateLevelGen.ts`，數值 `src/run/data/deliberateLevels.ts`）：中間有缺口的隔牆（可能有門；精英／頭目關卡要先拉絞盤）、少數敵人分成小隊放在正面、側翼、草叢埋伏、門後與後方。敵人**看到英雄（或被打）才警覺，同小隊一起進攻**；目標依權重評分（距離、生命、後排、仇恨、狀態、現任；嘲諷最優先）。新敵人：盾兵（生命過半前防禦較高，跌破後「破盾」）、衝鋒兵（紅色預兆帶後直線衝鋒）、刺客（落點預兆圈後跳過來）、鉤手（紅線預兆後把後排拉過去，擋住視線就落空）、祭司（綠線預兆，長準備治療同伴）、召喚師（召喚圈後叫出 3 隻屍僕）、自爆屍（貼近後倒數，地上顯示爆炸範圍）。
遊俠的主動技能是瞄準射擊；法師的火球準備完成後**立即爆炸**（沒有飛行時間）；沉穩節奏的所有關卡都有戰爭迷霧。英雄卡最上面是頭像（目前是色塊佔位：平時朝左的側臉，選取時轉成正面）。
**法師火球**：按下後不用等準備，直接丟出，有飛行時間、落點顯示爆炸範圍，放完進冷卻（2026-10-20 拿掉充能／大火球）。**交戰距離**：沉穩節奏的普攻射程、技能施放距離、敵人察覺距離、攻擊移動接戰距離都 ×0.6（`DELIBERATE_PACE.range`）。
**技能循環（S5-4）**：咒術師是**衰弱詛咒 → 詛咒爆裂**（引爆目標身上的詛咒，傷害較高並解除詛咒）→ 衰弱詛咒…，鈕上小字預告下一招。資料在 `src/sim/data/cycles.ts`。
**裝備道具（S5-5）**：每名英雄 2 個道具欄，每件道具是一個被動（`src/sim/data/items.ts`；舊的共用技能回收成道具效果，例如鐵盾＝盾擊、寒霜指環＝冰縛、沼澤苔＝沼澤）。取得方式：路線圖上的**商人**（💰）用金幣買，或打贏戰鬥時機率掉落（精英必掉、稀有機率較高）。在路線圖的「🎒 背包與裝備」或商人畫面裝備／卸下。規則在 `src/run/items.ts`，數值在 `src/run/data/economy.ts`。
節奏倍率在 `src/sim/data/deliberate.ts`（移動 ×0.6、行動時間 ×1.8、冷卻 ×2，佔位）。舊的怪群與戰術模式已封存，切換方式見 `src/run/data/levels.ts` 的 `expeditionStyle`。

## 畫面投影

戰鬥畫面預設為 45 度等角（2:1）投影：角色是「腳下橢圓＋直立長方形」，障礙物是有高度的方塊，走到牆後會顯示半透明輪廓。
投影只在畫面層（`src/game/render/projection.ts`），sim 仍然用公尺的平面座標；除錯面板可即時切回正俯視比較。
投影參數在 `src/config.ts`（`projection`、`iso`），角色身高與障礙物高度在 `src/game/render/visual.ts`。

等角畫面預設逆時針轉 90 度（`config.isoRotation = 90`）：世界 +x（英雄 → 敵人的方向）朝螢幕右上，玩家以「往右上進攻」為主；設成 0 可回到原本的方向。

所有戰鬥地圖在規則層都是 48 × 48 公尺的正方形：原本的配置橫向拉開 1.2 倍（雙方起始距離更遠）、置中後上下補地帶，並在中間與上下兩側補上依主題而定的小型地形（岩石、樹叢、草叢、矮籬、淺水、石柱），每塊都確認不會擋住出生點之間的通路。

## 美術試裝：Flare 等角素材

`config.art = 'flare'` 時，等角戰鬥中的英雄、敵人與地板改用 [Flare](https://github.com/flareteam/flare-game) 的素材；除錯面板「美術」可即時切回色塊。
素材授權為 **CC-BY-SA 3.0**（見 [ASSET_LICENSES.md](ASSET_LICENSES.md)），標題畫面「製作人員」列出美術貢獻者。
重新產生素材：依 `tools/importFlare.py` 開頭說明 sparse checkout flare-game 後執行 `python3 tools/importFlare.py <路徑>`（需要 Pillow）；對應與縮放在 `src/game/render/flareArt.json`。

## 美術試裝：自製 3D 預渲染英雄（heroes3d）

`config.art = 'heroes3d'`（預設）時，戰士、遊俠、法師、牧師、咒術師（sorceress）改用 `public/assets/heroes3d/` 的自製 sprite（格式見該資料夾的 README.md）；
沒有素材的英雄（狂戰士、盜賊、煉金術士）、敵人與地板沿用 Flare。除錯面板「美術」可切回 Flare 或色塊，「法師外觀」可切換 mage／sorceress。
- 縮放：`config.heroes3dScale`（預設 0.75，對齊身高方塊）；個別角色的倍率在 `src/game/render/heroes3dArt.json` 的 `scaleMul`
- 動作對應、各動作「最用力（生效）」的影格（`peaks`）、替代順序、暫不使用的動作（`avoid`）都在 `heroes3dArt.json`
- 節奏：準備期間依進度播到 peak 的前一格，生效那一刻剛好是 peak，恢復期間播完剩下的影格（`src/game/render/heroes3dAnim.ts`）

### 地形物件（props3d）

heroes3d 模式下，地圖上的地形物件改用 `public/assets/props3d/` 的自製物件（格式見該資料夾的 README.md）。**只換外觀**，格子、碰撞、規則仍由地圖資料決定：
- 小型、近似方形的障礙物 → 石頭、樹樁、木箱、木桶堆、苔石組、樹根土坑（依大小與地圖主題挑選；戶外地圖不放木箱木桶）
- 矮籬（掩體）→ 兩排倒木；草叢（隱匿）→ 灌木，燒掉的格子會隱藏
- 長條的牆、懸崖、深水、頭目戰的柱子還沒有自製物件，維持方塊
- 物件依地面原點的深度排序；高的物件會遮住後面的角色（畫輪廓）
- 對應、縮放（`scale`、`fitMin`／`fitMax`）、各地圖的物件池都在 `src/game/render/props3dArt.json`

## 部署到 GitHub Pages

`.github/workflows/deploy.yml` 會在 `main` 有新提交時跑測試、打包並部署。第一次使用需要到

## 專案結構

```
src/sim/      純 TypeScript 模擬層（不 import Phaser／DOM，只吃 Command、只吐 SimEvent）
  world.ts      World：step()、enqueue()、移動、指令處理
  actions.ts    準備／生效／恢復狀態機、打斷、效果結算
  combat.ts zoc.ts los.ts rng.ts
  nav/          格子、A*、路徑平滑、避讓、近戰站位
  ai/           敵人 AI、英雄閒置行為（IdleBehavior 介面）
  data/         英雄、敵人、技能、地圖（arena01.json）
src/game/     Phaser 畫面層：場景、渲染、輸入（輸入 → Command）
src/config.ts 時間倍率、ZOC 模式、自動暫停、快捷鍵
src/run/      遠征模組（純 TypeScript）：RunState、路線圖生成、節點流程、強化、事件；data/ 放經濟、遭遇、強化、事件
tools/        autobattle／autorun（無畫面單場／整趟）、heroScript（腳本英雄 AI）、runPolicy（自動遠征決策）、encounterStats、trace（除錯）
tests/        Vitest（只測 sim）
```
