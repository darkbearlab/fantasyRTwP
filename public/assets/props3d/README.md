# 自製 3D 預渲染地形物件（props3d）—— 試作第一批

Poly Haven 實景掃描模型（**CC0**）用與 `heroes3d` 相同的相機與光源渲染成的單張物件圖，讓地形物件和自製英雄質感一致。
總覽圖：`docs/art/props3d_preview.png`（放在 Flare 草地上、旁邊有戰士對照比例）。

## 圖檔格式
- 每個物件一張 PNG（透明背景，含落在地面的影子）。
- `index.json`：每個物件的 `w`、`h`（圖寬高 px）、`origin`（**地面原點**在圖內的像素座標，物件放置點對齊這裡）、`size_m`（物件實際尺寸，公尺）。
- 比例與英雄相同：約 **53.3 px／公尺**；相機正交、俯角 30°、方位 45°。
- 物件只有一個角度（不需要 8 方向）。

## 已知問題
- 尺寸未依遊戲格子調整：苔石組偏大、倒木偏細，接入時可先用縮放處理，之後我會重渲。
- 樹木（Poly Haven 樹模型面數過高）、石牆、廢墟尚未製作；這些暫時用 Flare 的物件（`flare_grassland_objects` 等，CC-BY-SA）。

## 重新產生
`tools/props3d/props.py`（Blender bpy 模組）：
`python3 -I props.py <模型.gltf> <輸出.png> [旋轉角度] [縮放]`
原始模型存放在作者電腦（`D:\_遊戲素材\3D模型\PolyHaven\`），不提交進 repo。
