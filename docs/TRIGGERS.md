# 觸發框架設計手冊

> 給設計用的參考（Alan，2026-10-24）。說明怎麼用「觸發」幫英雄、道具、升級設計效果，讓普攻也有 build 的空間。
> 程式在 `src/sim/triggers.ts`；試作道具在 `src/sim/data/items.ts` 的最後一段。數值全部是佔位。

---

## 1. 這是什麼

一個**觸發**就是一句話：「**當〔事件〕發生，如果〔條件〕成立，就〔效果〕。**」

例：
- 當**普攻打中**，如果**目標被標記**，就**追加傷害並消耗標記**。（處刑者之斧）
- 當**被打**，就**反擊攻擊者**，每 1 秒最多一次。（荊棘甲）
- 當**放出技能**，就**治療身邊的英雄**。（禱念珠）

一個被動可以掛好幾個觸發，一個觸發可以有好幾個效果。

## 2. 可以掛在哪裡

觸發是「被動」的一部分，所以凡是有被動的地方都能掛：

| 來源 | 寫在哪裡 | 說明 |
|---|---|---|
| 裝備道具 | `src/sim/data/items.ts` | 每件道具就是一個被動，加上 `triggers` 欄位即可 |
| 升級（昇變的分支、通用升級） | `src/sim/data/passives.ts` 寫被動，`src/run/data/upgrades.ts` 用 `passive: 'id'` 指過去 | 升級選到後英雄得到這個被動 |
| 職業被動 | `src/sim/data/passives.ts` | 職業天生的被動 |

> 隨從目前沒有被動，不會觸發。之後如果要「隨從也能觸發」，可以再開。

## 3. 事件（`on`）

| 事件 | 什麼時候 | 「目標」是誰 |
|---|---|---|
| `hit` | 自己打中（目標沒有倒） | 被打中的敵人 |
| `crit` | 自己爆擊（目標沒有倒） | 被打中的敵人 |
| `kill` | 自己打倒目標 | 被打倒的敵人 |
| `miss` | 自己沒打中 | 沒打中的那個敵人 |
| `dodge` | 對方沒打中自己 | 攻擊自己的人 |
| `hitTaken` | 自己受到傷害 | **打自己的人**（反擊、荊棘用） |
| `skillCast` | 自己放出技能（生效的那一刻） | 技能的目標（沒有目標的技能就沒有） |

注意：
- 打倒目標的那一下**只算 `kill`**，不算 `hit`、`crit`。
- `hit`、`crit`、`kill`、`miss` **預設只算普攻**。要連技能也算，加 `source: 'any'`。

## 4. 條件

全部都是可選的，寫幾個就要同時成立幾個。

| 條件 | 寫法 | 意思 |
|---|---|---|
| 每第 N 次 | `every: 4` | 這個觸發的事件每發生 4 次才觸發一次（每個觸發各自計數） |
| 機率 | `chance: 0.3` | 30% 機率 |
| 冷卻 | `cooldown: 3` | 觸發後 3 秒內不再觸發 |
| 算哪些攻擊 | `source: 'any'` | 技能造成的命中、爆擊、擊殺也算（預設只算普攻） |
| 只算某些技能 | `skillIds: ['charge']` | 只有這些技能才算；要配 `source: 'any'`（`skillCast` 不用） |
| 目標身上有狀態 | `targetHas: 'marked'` | 見下表 |
| 目標的階級 | `targetRank: 'elite'` | `normal` 一般、`elite` 精英隊長、`boss` 頭目 |
| 自己生命低於 | `selfHpBelow: 0.4` | 自己生命低於 40% 才觸發 |
| 從背後 | `behind: true` | 攻擊者在目標背後（目標面向的反方向左右各 60° 內） |

`targetHas` 可以用的狀態：

| 狀態 | 意思 |
|---|---|
| `stunned` | 暈眩中 |
| `rooted` | 定身中（含冰縛） |
| `burning` | 燃燒中 |
| `cursed` | 詛咒中 |
| `chilled` | 寒氣減速中 |
| `sundered` | 破甲中 |
| `marked` | 被標記 |
| `lowHp` | 生命低於 30% |

## 5. 效果

### 打在目標身上

| 效果 | 寫法 | 意思 |
|---|---|---|
| 暈眩 | `{ kind: 'stun', duration: 0.5 }` | 暈眩 0.5 秒 |
| 定身 | `{ kind: 'root', duration: 1 }` | 不能移動 1 秒（還能攻擊） |
| 燃燒 | `{ kind: 'burn' }` | 點燃（持續扣血） |
| 破甲 | `{ kind: 'sunder', armor: 2, maxStacks: 3, duration: 4 }` | 護甲每層 −2，最多 3 層 |
| 地面區域 | `{ kind: 'zone', radius: 1.2, lingering: {…} }` | 在目標腳下留下持續區域（例：沼澤減速） |
| **標記** | `{ kind: 'mark', vuln: 0.15, duration: 4 }` | 目標受到的傷害 +15%，4 秒。**給其他英雄接著打用** |
| **引爆** | `{ kind: 'detonate', mult: 1, consume: true }` | 追加「自己基本傷害 × 1」的傷害；`consume` 會同時移除 `targetHas` 指定的狀態 |
| **連鎖** | `{ kind: 'chain', mult: 0.5, count: 2, radius: 3 }` | 從目標彈到附近 3 m 內另外 2 名敵人，各受 0.5 倍傷害 |

### 回饋自己（或隊友）

| 效果 | 寫法 | 意思 |
|---|---|---|
| **減冷卻** | `{ kind: 'cooldown', seconds: 1.5 }` | 自己所有技能的冷卻 −1.5 秒 |
| **冷卻轉好** | `{ kind: 'resetCooldown' }` | 自己所有技能立刻可以再用 |
| **回血** | `{ kind: 'heal', pct: 0.06 }` | 自己回復 6% 最大生命 |
| **疊增益** | `{ kind: 'empower', damagePct: 0.1, duration: 6, maxStacks: 3 }` | 造成傷害每層 +10%，最多 3 層；再觸發會加一層並刷新時間 |
| **治療隊友** | `{ kind: 'healAllies', pct: 0.06, radius: 6 }` | 自己身邊 6 m 內的英雄（含自己）回復 6%；隨從不吃 |

細節：
- **引爆、連鎖的傷害** = 自己普攻的基本傷害（含自己的傷害加成）× 倍率。不判定命中，類型和自己的普攻相同。
- **標記**不會疊加：同時有兩個標記時取比較高的那個，時間取比較長的。
- **疊增益**只有一組：不同來源的增益共用層數，倍率用最後觸發的那一個。

## 6. 規則與保護

- **連鎖反應最多兩層**：觸發的效果又引起觸發（例：兩邊都有荊棘甲）時，最多連到第二層就停，不會無限反彈。
- **觸發時英雄頭上會跳被動的名字**，方便看出哪個東西觸發了。
- **舊的寫法 `onHit`**（每第 N 下、機率的暈眩、定身、燃燒、破甲、區域）照常可用，行為和以前一樣。新設計建議直接用 `triggers`。
- 每第 N 次是**每個觸發各自計數**；舊的 `onHit` 則是用「普攻命中總數」計數。

## 7. 寫法範例

道具（`items.ts`）：

```ts
executionerAxe: item('executionerAxe', '處刑者之斧', 'rare', 120,
  '普攻打中被標記的目標時引爆標記：追加 1 倍傷害並消耗標記', {
  triggers: [{ on: 'hit', targetHas: 'marked', effects: [{ kind: 'detonate', mult: 1, consume: true }] }],
}),
```

升級用的被動（`passives.ts`），再從 `upgrades.ts` 用 `passive: 'rangerMarks'` 指過去：

```ts
rangerMarks: {
  id: 'rangerMarks', name: '鎖定', source: 'class',
  description: '普攻命中時標記目標 3 秒（受到傷害 +20%）',
  triggers: [{ on: 'hit', effects: [{ kind: 'mark', vuln: 0.2, duration: 3 }] }],
},
```

一個觸發多個效果、加條件：

```ts
triggers: [{ on: 'crit', targetRank: 'elite', cooldown: 5,
  effects: [{ kind: 'stun', duration: 1 }, { kind: 'cooldown', seconds: 2 }] }]
```

## 9. 設計配方（可以照這些方向發想）

- **跨英雄連鎖**：一人「掛狀態」，另一人「看狀態加成或引爆」。
  - 遊俠標記 → 戰士引爆。
  - 法師點燃 → 牧師打燃燒中的目標時治療隊友（`targetHas: 'burning'` + `healAllies`）。
  - 寒氣減速 → 刺客打減速中的目標必定……（`targetHas: 'chilled'`）。
  - 這類設計讓**隊伍組成本身就是 build**，也讓暫停下指令「誰先打誰」有意義。
- **普攻餵技能**：`every` + `cooldown` 效果、`kill` + `resetCooldown`。只有一招主動技能時，這會讓那一招的使用頻率變成 build 的核心。
- **爆擊流**：`crit` + `empower`／`chain`。配命中、爆擊相關的道具。
- **位置流**：`behind` 背刺；之後可以加「側面」「高處」等條件。
- **坦克反擊流**：`hitTaken` + `detonate`／`empower`，配嘲諷光環。
- **風險流**：`selfHpBelow` 讓殘血時變強，配吸血或回血。
- **針對精英**：`targetRank: 'elite'` / `'boss'`，做「專打大隻」的道具。

設計時的提醒：
- 觸發頻率高的效果（每下普攻都會觸發）數值要小，或加 `cooldown`／`every`。
- 「引爆並消耗」比「純加傷」更有節奏感：需要隊友先上狀態，打出來的時機也比較明確。
- 疊增益目前只有一組，太多疊增益道具一起帶會互相覆蓋（之後需要可以改成分開計算）。

## 10. 還沒有、之後可以加的

- 事件：隊友倒下、自己被治療、敵人進入範圍、戰鬥開始、被暈眩、打斷成功。
- 條件：從側面、自己在高處、身邊有幾名隊友／敵人、目標正在準備技能、自己的技能正在冷卻。
- 效果：給隊友增益、召喚隨從（接隨從系統）、擊退、拉近、隱身、清除自己的負面狀態。
- 數字顯示：疊增益的層數、標記剩餘時間在英雄卡或頭上的顯示。
