## 1. 遊戲現況（一段話版）

fantasyRTwP 是即時制、可暫停（RTwP）的小隊 roguelite，用 Phaser 3 和 TypeScript 做的網頁遊戲。

- **故事**：王國首都淪陷，四名英雄出發尋找魔法水晶。突圍時被打散，開局只有兩人，其他人要在路上解救。全程五章：首都突圍、野外、地城、密道、魔王城。
- **流程**：一路向前的連續地圖，在地圖上整備（換裝、買東西），英雄陣亡就是沒了。
- **戰鬥**：「沉穩節奏」。
  - 每名英雄只有**一招主動技能**，普攻和走位交給 AI；
  - 敵人的大招有預兆、可以被打斷；
  - 有失衡值：把敵人打到失衡就會暈眩，集中火力有回報。

## 2. 目前的成長系統

| 系統 | 現況 |
|---|---|
| 等級 | 全隊共用一個等級，經驗值只來自擊殺。每升一級，全隊生命和傷害 +3%。 |
| 升級選項 | 每升一級，每名英雄從自己職業的升級裡三選一，包括分支升級和職業被動升級。 |

| 主動技能 | **沒有等級**，由職業決定，玩家不能選。 |
| 道具 | 武器、防具、飾品各一格（2026-10-29 剛改）。道具是被動效果，有一部分帶觸發器（見 `docs/TRIGGERS.md`）。 |
| 消耗品 | 全隊共用的包包，例如藥水、煙霧彈。 |

## 3. 到目前為止的討論結論

### 3.1 路線：不在「類 Diablo」和「小隊戰術」之間二選一
- **整個隊伍就是一個 Diablo 角色，每個英雄是它的一個技能欄。** 四個英雄各一招主動，按鍵數量和 Diablo 差不多。
- **戰鬥內**：少量、但份量重的決定，也就是什麼時候按、打誰、站哪裡。平常的普攻和跟隨交給 AI。
- **戰鬥外**：用裝備和技能選擇組 build。
- 地城圍攻一代的教訓：自動戰鬥強到玩家的決定不重要，被批評「遊戲自己在玩自己」。預兆、打斷、失衡、潛行這些機制，就是用來讓玩家的操作改變結果。
- 對「預兆會讓玩家無敵」的回應：難度不是來自看不到，而是來自三點：
  - 應對要花資源（冷卻、少打幾下）；
  - 威脅會重疊；
  - 四個人的站位要顧。

### 3.2 裝備：會改變打法的，才捨不得換
- Diablo 2 能用很久的裝備，給的是不會過時的東西：+技能等級、門檻（施法速度的斷點）、功能型效果、只給特定 build 的效果。
- 本作的對應：
  - 觸發器綁在戰鬥的關鍵字上：失衡、打斷、標記、偷襲、爆擊等級、背後、預兆。
  - 職業被動 +1 級（已做）。
  - 失衡值可以當作「門檻」。
- 純數值的裝備保留，滿足「想堆數值」。

### 3.3 主動技能的選擇（方向已定，細節待討論）
- **要給選擇，但只在戰鬥外換**，在整備時換，進戰鬥就固定。戰鬥中切換會讓四個人的操作變複雜。
- 選擇要有意義，出發前最好能看到下一張圖的情報，例如「弓手多、有精英」。
- 有兩種做法：
  1. 每個職業多 1 到 2 招完全不同的主動技；
  2. 同一招的變體，類似 Diablo 3 的符文，例如潛行・持久、潛行・伏擊。
- 我（實作 session）原本建議先做變體，搭配「主動技能升到 2 級解鎖一個變體」。**Alan 決定和具名角色一起討論。**

### 3.4 像素對齊：擱置
試過後製濾鏡，細線和文字會被吃掉。真正做對要重畫戰鬥中的指示物，很多現代像素遊戲也沒這樣做，所以先擱置。除錯面板裡的開關還在，預設關閉。

### 4.4 從盤點看得出的問題（給討論參考）
- **進階職業的主動技能重複**：
  - 守護者、角鬥士都和戰士一樣是盾擊；
  - 連弩手和遊俠一樣是瞄準射擊；
  - 狂信者和牧師一樣是聖域。
  
  昇變後差在被動，操作手感沒有變。
- **法師的定位和主動對不上**：定位寫「範圍爆發」，主動卻是給隊友加傷害的附魔。爆發其實來自普攻的火彈。
- **主動技能沒有成長空間**：沒有等級，也沒有變體，裝備的「+技能」效果只能加在職業被動上。
- **技能的關鍵字覆蓋**：打斷有盾擊、瞄準射擊、聖鎚；失衡主要靠盾擊；標記只有道具有。

  哪些關鍵字缺少主動技能去「製造」或「利用」，可以在技能矩陣裡檢查。

## 5. 業界參考：技能池怎麼設計（摘要）

1. **先定角色的核心動詞**，一句話說出他在戰鬥中做什麼，所有技能都是這個動詞的變化。
2. **用矩陣檢查**：每招填這四項，找出重疊和缺口：
   - 功能：傷害、控制、位移、防禦、輔助；
   - 範圍：單體、直線、扇形、區域、全隊；
   - 時機：瞬發、讀條、持續、陷阱；
   - 它回答什麼狀況：對付遠程、成群的敵人、王，或是救人。
3. **每招都要碰到共用的關鍵字**：失衡、打斷、標記、偷襲、爆擊等級、背後、預兆。這樣技能、裝備、觸發器才會串起來。
4. **同一角色的幾招各自在不同情況最好用**，換技能才有意義。
5. **強度預算**：每招換算成「相當於幾秒普攻的傷害」，控制和位移也給換算值，先抓出明顯過強或過弱的。
6. **預期會砍掉一半**：先用最便宜的方式做出來試玩。

從切片增厚的一般順序：
1. 寫設計支柱；
2. 凍結核心規則；
3. 訂內容預算；
4. 先做完整一章當範本，再複製；
5. 用組合增加變化：敵人詞綴、地圖修飾、難度階層；
6. 固定的試玩節奏。

## 6. 待討論的議題

依建議的順序：

1. **設計支柱**：三、四條核心原則。3.1 的結論可以當起點。
2. **主動技能的選擇規則**：
   - 做變體，還是多招完全不同的技能？還是兩者都有？
   - 怎麼取得：升級、昇變、道具、事件？
   - 什麼時候能換？整備時隨時換，還是只在營地？
   - 主動技能要不要有等級？等級帶來什麼，數值還是解鎖變體？
   - 技能循環的職業（咒術師、狙擊手、死亡法師）怎麼納入？
3. **具名角色**：
   - 角色和職業的關係：一個角色固定一個職業？角色有自己的專屬技能或被動？
   - 角色和昇變的關係：昇變方向是角色決定，還是玩家選？
   - 先做哪 2 到 3 個角色當第一次量產測試？
4. **每個角色的技能池**：用第 5 節的矩陣，每人列 3 招左右，寫出核心動詞、每招回答的狀況、碰到的關鍵字。
5. **舊技能池的處理**：哪些值得救回來改成沉穩節奏版本，哪些丟掉。
6. **內容預算**（可以之後再談）：
   - 正式版大概要幾個角色、幾件裝備；
   - 每章幾種敵人。
